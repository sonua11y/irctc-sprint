# 🚆 IRCTC Design Engineering & AI Sprint

## Project Overview

This repository contains my submission for the **IRCTC Design Engineering & AI Feature Sprint**. The objective of this project is to identify critical user experience, performance, and reliability issues within the IRCTC platform and propose scalable, user-centered solutions.

The project is divided into two phases:

### Part A — Problem Discovery

In this phase, I explored the IRCTC platform and documented six major user pain points, including:

* Tatkal booking failures during peak traffic
* Unreliable search filters
* Seat selection reset issues
* Refund tracking challenges
* Lack of guidance in PNR status checks
* Mobile booking usability problems

Each problem includes:

* Problem description
* Affected user groups
* Frequency analysis
* Step-by-step user flow
* Failure point identification

### Part B — Solution Design

This phase focuses on designing solutions for the identified problems through:

* Product specifications
* UX improvements
* AI-powered features
* Prioritization matrix
* Technical implementation considerations
